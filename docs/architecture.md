# Базовая архитектура Fashion Store

## Контексты (модули монолита)

- `Auth`: регистрация/логин, сессии, роли.
- `Catalog`: товары, категории, остатки, цены, баннеры.
- `Cart`: корзина гостя и пользователя.
- `Checkout`: заказ, оплата, доставка, статусы.
- `Outfits`: пользовательский конструктор образов.
- `StylistLooks`: готовые образы от стилистов.
- `Wishlist`: избранное пользователя.
- `Admin`: управление карточками, баннерами, stylist looks.

## Границы ответственности

- `Next.js`:
  - страницы, SEO, UI;
  - BFF-слой для легкой агрегации данных;
  - админские интерфейсы.
- `NestJS`:
  - бизнес-правила;
  - централизованный auth/access control;
  - интеграции оплаты/доставки;
  - вебхуки и фоновые процессы.

## База данных (первый этап)

- PostgreSQL:
  - `users`, `products`, `categories`, `product_images`
  - `carts`, `cart_items`
  - `orders`, `order_items`, `deliveries`, `payments`
  - `outfits`, `outfit_items`, `stylist_looks`
  - `wishlists`
- Redis:
  - сессии
  - кеш каталога/баннеров
  - временные данные конструктора
